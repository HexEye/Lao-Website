Core Documentation

Getting Started

Lao is designed to be highly readable and easy to adopt. To run your first Lao script, ensure you have the required core files (lao.lua, lua55.dll, and lua55.exe) in your workspace. You can easily initiate your development environment using the provided start.bat file.

Syntax & Structure

Built on top of the powerful Lua engine, Lao transforms complex programming structures into a deeply intuitive syntax. It aims to bridge the gap between technical execution and everyday language, allowing absolute beginners to understand logic flows instantly.

Why Lao?

Traditional languages often overwhelm learners with rigid symbols. Lao provides an ultra-readable learning platform while maintaining the lightweight performance, custom scripting capabilities, and flexibility of Lua.
